# 💍 Dream Wedding Planner

An Android application developed using **Java** and **Android Studio** that helps couples efficiently plan their wedding by managing budgets, tracking expenses, organizing checklists, viewing live USD exchange rates, and exploring wedding inspiration through REST APIs.

---

## 📱 Features

- 💰 Wedding Budget Tracker
- 📊 Expense Management
- ✅ Wedding Checklist
- 💵 Live USD Exchange Rate (REST API)
- 🖼️ Wedding Inspiration Gallery (REST API)
- 🎨 User-Friendly Material Design Interface

---

## 🛠️ Technologies Used

- Java
- Android Studio
- XML
- REST APIs
- JSON
- RecyclerView
- CardView
- Material Design Components

## 🚀 How to Run

1. Clone this repository.
2. Open the project using Android Studio.
3. Sync Gradle files.
4. Run the application on an Android Emulator or a physical Android device.

---

## 🎯 Project Objectives

The objective of this application is to simplify wedding planning by providing users with a single platform to:

- Manage wedding expenses
- Monitor the overall budget
- Track wedding tasks
- View live USD exchange rates
- Browse wedding inspiration images
